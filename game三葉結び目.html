結び目 領域選択ゲーム (3値モード)

目標：すべての交点を OFF（消灯）にしよう！

ステージ選択

状態カウンター OFF: 0 赤: 0 青: 0
手数 (Moves) 0
経過時間 00:00
領域をクリックしてすべての交点を OFF にしよう！

ゲームのルール

1

領域（面）をクリックすると、境界にあるすべての交点が OFF ➔ 赤 ➔ 青 ➔ OFF の順に変化します。

2

すべての交点を綺麗に OFF（消灯） に戻せばステージクリアです！

トポロジーと領域選択パズル

結び目領域選択パズルです。モジュロ3の演算により、複数の色を組み合わせながらすべての交点を消灯させるパズル性を持っています。
